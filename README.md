# Arkanoid
Klasyczna gra typu "brick breaker" zamknięta w jednym, lekkim pliku. Bez zbędnych instalacji, bez skomplikowanej konfiguracji. Czysta rozrywka.

📖 O projekcie
Ten projekt to minimalistyczna implementacja gry Arkanoid (znanej też jako Breakout). Głównym celem było stworzenie w pełni grywalnej aplikacji, która mieści się w pojedynczym pliku kodu źródłowego.

Jest to idealny przykład na to, jak stworzyć prostą pętlę gry, obsługę kolizji i renderowanie grafiki bez użycia ciężkich silników graficznych.

✨ Główne cechy
Zero zależności: Nie musisz pobierać tysiąca bibliotek (node_modules itp.), aby zagrać.

Portable: Wystarczy jeden plik – możesz go wysłać mailem, wrzucić na pendrive'a lub uruchomić na dowolnym komputerze.

Mechanika:

Sterowanie paletką.

Fizyka odbić piłki.

System zbijania cegieł.

Licznik punktów i system "Game Over".

Czysty kod: Kod jest skomentowany i zorganizowany, służąc jako świetny materiał edukacyjny.
